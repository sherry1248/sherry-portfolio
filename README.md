# Sherry — Developer Portfolio

개인 개발자 포트폴리오의 첫 번째 프론트엔드 버전입니다. React + TypeScript + Vite로 만들어졌습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 터미널에 표시된 주소(보통 `http://localhost:5173`)로 접속합니다.

## 구성

- `src/App.tsx`: 페이지 콘텐츠, 프로젝트 상세 모달 및 링크
- `src/components/Terminal.tsx`: Arch Linux 스타일 터미널 및 타이핑 효과
- `src/styles.css`: 다크 테마, 반응형 레이아웃, 프로젝트용 CSS 아트
- `public/avatar.jpg`: 사용자가 제작한 개발자 프로필 이미지

## 콘텐츠 표현 원칙

- `Hypatia`, `Autonomous Driving`은 진행 중인 개인 프로젝트로 표기했습니다.
- `스쿨존맵`은 AI SCHOOL 9기 MID PROJECT 최우수상 수상작입니다.
- `MindMate`는 AI SCHOOL 9기 FINAL PROJECT 최우수상 수상작이며, 개인 담당 역할은 Django 웹 구현 중심으로 기재했습니다.
- 데이터톤(SVHN)은 기존 팀 수상 경력으로만 표시하고, 향후 개인 CNN 재구현과 구분합니다.
- 개발 경험을 과장하는 숙련도 %는 표시하지 않습니다.

## 주의

이 저장소는 공개용 완성본이 아닌 작업용 첫 버전입니다. 수상 증빙 PDF, 이전 팀원의 소스 코드, 데이터셋은 자동으로 공개하지 않습니다.
